# Contributing to Bastion Orbit

Thanks for your interest! Bastion Orbit is part of the SlothLabs suite alongside CloudOrbit and DataOrbit.

## Quick start

```bash
npm install
npm run dev         # browser mode with mock data
npm run tauri dev   # full Tauri app
```

## Guidelines

- Keep PRs focused — one feature or fix per PR.
- Run `npm test` and `npm run test:interactions` before opening a PR.
- For Rust changes, run `cd src-tauri && cargo test`.
- Match the existing teal/emerald color tokens — don't introduce new colors.
- No co-authored attribution in commit messages.

## Issues

Open an issue at https://github.com/slothlabs/bastionorbit/issues.
